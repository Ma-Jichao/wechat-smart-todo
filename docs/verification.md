## 验证的限制与待完成项

- 全新 Linux 从安装官方包到扫码、启动 systemd 的完整安装尚未实测。没有在生产服务器执行安装脚本。
- 已有实例的新库创建、角色权限、迁移、备份恢复已在隔离实例实测；部署中的真人扫码和正式服务注册仍需独立新环境验收。
- rpm 系发行版与 arm64 仅实现安装分支，未完成整机验证，不能宣称所有 Linux 版本均支持。
- test_llm_behaviour 默认跳过；真实模型理解和更换模型服务商的兼容性未在本轮验证，不使用付费调用冒充离线结果。
- 真实语音到建事项、隔夜无互动后的 08:00 实收、真实网络故障、登录过期重新绑定还需真人及真实时间窗口。
- 真实通道无送达回执，接口 accepted 不能当作实际实收；不主动冲击限流阈值。
- 原有 24 项验收的部分历史状态不等于本轮全部通过，本记录只描述本轮取得的证据。

## 公开版修复边界

本次公开源码修复了阻塞队列的完成/修改联动、发送前版本检查、超时重试上限及重复提醒文案更新。现有线上部署未同步这些修改。迁移文件字节保持原样，避免破坏已应用版本的哈希校验；其中历史章节注释不依赖任何私人文档运行。
